## Publish on GitHub Pages
1. Replace the files in your `sc8658-sketch/kamal.vidyapeeth` repository with the files in this folder.
2. Commit the changes to the `main` branch.
3. Keep GitHub Pages set to `main` + `/(root)`.
4. Test:
   https://sc8658-sketch.github.io/kamal.vidyapeeth/
   https://sc8658-sketch.github.io/kamal.vidyapeeth/sitemap.xml
   https://sc8658-sketch.github.io/kamal.vidyapeeth/robots.txt

## Google Search Console
1. Open Google Search Console.
2. Add/verify the URL-prefix property:
   https://sc8658-sketch.github.io/kamal.vidyapeeth/
3. Use URL Inspection and request indexing for the homepage.
4. Open Sitemaps and submit:
   sitemap.xml
5. Monitor Page Indexing and Performance reports.

## Important
- SEO improves discoverability but does not guarantee a #1 ranking.
- Keep business details, phone numbers, services and location accurate.
- Get genuine reviews from real students/parents; do not buy or fabricate reviews.
- If you later move to a custom domain, update `SITE_URL` values in canonical tags, JSON-LD, robots.txt and sitemap.xml.
