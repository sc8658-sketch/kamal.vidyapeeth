# Kamal Vidyapeeth Website

A responsive, static website for Kamal Vidyapeeth, Raipur, Dehradun.

## Files
- index.html — website content
- style.css — responsive design
- script.js — mobile menu and WhatsApp enquiry form
- poster.jpeg — supplied admission poster

## Quick edits
Search in `index.html` for phone numbers, timings, dates, faculty details or course information if anything needs changing.

## Publishing
This is a static website, so it can be hosted on GitHub Pages or another static hosting service.

For GitHub Pages:
1. Create a GitHub account.
2. Create a public repository.
3. Upload all files in this folder.
4. Go to Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select `main` and `/ (root)`, then Save.
7. Open the URL GitHub provides.

You can also use a repository named `YOURUSERNAME.github.io` for a user site.
